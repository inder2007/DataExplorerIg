# WPF_Infragistics_FlaUI_Advanced_POC:
Advanced POC to showcase functionality of WPF Infragistics Data controls and templates with FlaUI automation test cases.

This application elaborates the use of WPF Infragistics data controls, components and templates. Some real world use case scenarios of complex automations are added for reference.

Prerequisits:

Installation

Visual Studio 2022 or above
Microsoft Windows Desktop Runtime 8.0.27 win-x64
FlaUI Inspect 3
Nuget Packages:

FlaUI2
FlaUI3
Newtonsoft.Json 13.0.3
Infragistics Trial components for WPF 23.2.290
Note: If you do not have access to Infragistics WPF/XAM trial controls, remove the package references from DataExplorer.csproj file and reset references from IgPackages folder which has downloaded assemblies.
